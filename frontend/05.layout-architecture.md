# 📐 Architecture du Layout - Data Skills Radar

## 1. Vue d'ensemble
L'application utilise un layout global (`MainLayoutComponent`) orchestrant trois éléments principaux :
- **Header** : Navigation supérieure, actions globales et profil.
- **Sidebar** : Menu latéral rétractable avec architecture Smart/Dumb Components.
- **Footer** : Pied de page statique.
  L'ensemble est basé sur **Angular 22 (Zoneless)**, propulsé par les **Signals** pour la réactivité, et stylisé avec **Tailwind CSS v4** et **PrimeNG** (Thème DeepTech / Glassmorphism : Teal & Ambre).

---

## 2. Sidebar Component (Menu Latéral)
La `SidebarComponent` agit comme un composant conteneur ("Smart Component") qui gère l'état d'ouverture (`isOpen` persisté dans le `sessionStorage`) et le distribue à ses trois enfants ("Dumb Components") via la nouvelle API `input()`.

### A. `app-sidebar-header`
- Affiche le logo (icône radar animée `animate-ping`) et le titre de l'application.
- Le texte disparaît de manière fluide (opacité) lorsque le menu est rétracté.

### B. `app-sidebar-menu`
- Gère la navigation par catégories (Général, Administration).
- Utilise un Signal pour définir la structure des routes francisées.
- **Design Web 3.0** : L'élément actif utilise un dégradé Tailwind (`bg-gradient-to-r`), une bordure néon gauche, un léger zoom (`scale-[1.02]`) et une ombre de lueur (`shadow-sm` colorée) pour un effet "Card Pop".

### C. `app-sidebar-user`
- Carte profil située en bas de la navigation.
- Écoute réactivement le signal `AuthService.userConnected`.
- Utilise des signaux `computed()` pour générer dynamiquement le nom complet, le rôle et les initiales de l'utilisateur.

---

## 3. Header Component (Barre Supérieure)
- **Communication** : Utilise l'API `output()` pour émettre l'événement `toggleSidebar` vers le Layout parent.
- **Zone Gauche** : Bouton menu Hamburger. (Espace réservé pour le futur `BreadcrumbComponent`).
- **Zone Droite** :
    - Badge utilisateur : Composant `<p-chip>` de PrimeNG dynamisé par les Signals du `AuthService`, arborant un style translucide (`bg-primary-500/10`, `backdrop-blur-md`).
    - Bouton de déconnexion gérant la destruction de session et la redirection sécurisée.

---

## 4. Tableau de bord (Dashboard - Design Pattern)
- Implémentation d'une grille réactive (`grid-cols-1 md:grid-cols-3`) avec des cartes aux effets Glassmorphism (`backdrop-blur-md`, `bg-surface-0/80`).
- Mixité des composants de données via des conditionnels de permission (`@if`).
- Typographie marquée : Utilisation de `font-space-grotesk` pour les compteurs chiffrés majeurs afin de renforcer l'identité "Big Data".
- Homogénéisation iconographique autour de la bibliothèque Google Material Icons.
