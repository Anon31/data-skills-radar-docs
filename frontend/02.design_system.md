# 🎨 Design System (Data Skills Radar)

**Version :** 1.3 (Alignement Implémentation v22 / Tailwind v4)  
**Mise à jour :** Octobre 2026

Ce document définit l'identité visuelle du **Data Skills Radar** et documente la configuration technique de notre interface décisionnelle (Web 3.0 / Deeptech).

## 1. Identité Visuelle & Palettes Sémantiques

Le thème repose sur des contrastes élevés, gérés dynamiquement via les modes Light et Dark, avec une alternance des couleurs primaires pour maximiser l'impact visuel selon le contexte :

* **Mode Clair (Light Mode ☀️) :**
    * **Surfaces :** Fonds lumineux basés sur la palette `Slate` (`#ffffff`, `slate.50`, etc.) pour un rendu propre et épuré.
    * **Couleur Primaire :** **Teal** (`teal.500`), apportant une touche fraîche et professionnelle pour le jour.

* **Mode Sombre (Dark Mode 🌙) :**
    * **Surfaces :** Fonds profonds type bleu nuit / Gunmetal (`slate.950` / `#020617`), idéal pour l'immersion et le travail prolongé.
    * **Couleur Primaire :** **Ambre / Or** (`amber.500`), offrant un contraste saisissant et un aspect "FinTech / Premium".

* **Typographie :** **Space Grotesk** (Google Fonts). Elle apporte un côté startup futuriste et géométrique, appliqué globalement sur la balise `<body>`.
* **Iconographie :** Google Material Symbols (Outlined).

## 2. Effets Visuels (Glassmorphism & Glow)

Pour éviter un design trop plat, nous utilisons des effets de profondeur :
* **Cartes (Glassmorphism) :** Les conteneurs utilisent des classes combinant transparence (`bg-surface-0/80` ou `bg-surface-900/80`) et `backdrop-blur-md` pour détacher les éléments du fond.
* **Glow (Ombres portées) :** Utilisé pour créer des effets de lueur autour des composants clés (Toasters, boutons de connexion).

## 3. Implémentation CSS (Tailwind v4 & PrimeNG 22)

L'architecture CSS s'appuie entièrement sur le moteur moderne de Tailwind v4 et le système de presets dynamiques de PrimeNG 22 :

1. **`app.config.ts` :** Configure le provider PrimeNG avec le preset `DsrTheme`, active le sélecteur de mode sombre via `darkModeSelector: '.dark'`, et définit l'ordre des couches CSS (`cssLayer: { name: 'primeng', order: 'theme, base, primeng' }`) pour éviter tout conflit de spécificité avec le reset de Tailwind.
2. **`src/styles/themes/dsr-theme.ts` :** C'est le cœur visuel. Un preset PrimeNG (basé sur *Aura*) qui gère les blocs `light` et `dark` pour les couleurs primaires (Teal ⇄ Amber) et les surfaces (`slate`). Il intègre aussi la personnalisation avancée des composants (ex: Toasters avec dégradés).
3. **`src/styles.css` :** Le point d'entrée minimaliste qui importe le cœur de Tailwind (`@import "tailwindcss";`), le plugin de pont PrimeNG (`@import "tailwindcss-primeui";`), les icônes PrimeIcons et les styles personnalisés.
4. **`src/styles/css/_base.css` :** Gère les styles fondamentaux du DOM (application de la police `Space Grotesk`, défilement fluide, etc.).

## 🌍 4. Environnement et SSR

* **Server-Side Rendering (SSR) :** Désactivé (`false`).
* **Justification :** Le SSR de Node.js entrerait en conflit avec l'exécution client-side de DuckDB-WASM. Notre application est un outil métier privé/BI interactif, le référencement SEO n'est pas un pré-requis.
